Seven Small Changes is a spot-the-difference game: three hand-drawn scenes, seven small changes hidden in each, a timer, hints, and a score that rewards a sharp eye. Find all seven to open the next scene.

## Play it

Serve the `game/` folder with any static server, then open `index.html` in a desktop browser:

```sh
cd game && python3 -m http.server 8080
```

Click a difference in either picture to mark it. `H` asks for a hint, `R` restarts the level.
